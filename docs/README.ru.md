# UGREEN NAS Download

[English](../README.md) · [Français](README.fr.md) · [🌐 34](LANGUAGES.md)

Приложение macOS и расширение Safari для отправки загрузок в приложение **Загрузки** NAS UGREEN под UGOS Pro, не оставляя страницу NAS открытой.

Исходники и версия DMG: **0.6.0**. Независимый общественный проект, не связанный с UGREEN или Apple.

## Особенности

- Перехват ссылок `.torrent` и `magnet:` на сайтах, авторизованных в Safari.
- Действие **Загрузить на NAS**, щелкнув правой кнопкой мыши ссылку, изображение, видео или аудиоэлемент, доступную напрямую.
- Ручная отправка URL из меню расширения.
- Аккаунт и сессия в Связке ключей macOS; Поддержка двухфакторной аутентификации и доверия устройств.
- Дополнительный поиск NAS с помощью онлайн-сервиса UGREEN или адрес HTTPS вручную.
- Список загрузок, прогресс и скорость; дополнительные уведомления о завершении, завершении работы и ошибках.
- Идентификация имен и типов файлов HTTP, с коррекцией имени после загрузки, когда файл однозначно идентифицирован.
- Собственные светлые и темные значки, а также логотипы Safari, адаптированные к теме системы.

## Совместимость

Проект настроен для **macOS 27 или новее** и скомпилирован с **Xcode 27.1** для Apple Silicon. Тесты NAS проводились с **DXP2800**, **UGOS Pro 1.20.0.0142** и **Загрузками 1.19.1.0004**. Другие версии не гарантируются: интеграция основана на наблюдаемых API без стабильного публичного контракта UGREEN.

## Установить из DMG

[Загрузить UGREEN NAS Download 0.6.0 для Mac Apple Silicon](https://github.com/cshxbe/UGREEN-NAS-Download/releases/tag/v0.6.0).

1. Откройте DMG, перетащите **UGREEN NAS Download** в **Приложения**, затем откройте приложение.
2. В **Safari → Настройки → Дополнительно** включите функции для веб-разработчиков. В разделе **Разработчик** включите **Разрешить неподписанные расширения**, затем включите **UGREEN NAS Download** в разделе **Расширения**.
3. Настройте NAS в настройках расширения.

Этот общедоступный пакет подписывается локально (специально) и не нотариально заверяется. macOS может заблокировать первоначальное открытие. Safari может попросить повторно включить разрешение для неподписанных расширений после выхода из браузера.

## Скомпилировать из исходников

1. Клонируйте этот репозиторий и откройте `Xcode/UGREEN NAS Download/UGREEN NAS Download.xcodeproj`.
2. В разделе **Подписание и возможности** выберите собственную команду Apple для двух целей: приложения и его расширения. Никакая персональная команда в репозиторий не введена.
3. Выберите схему **UGREEN NAS Download**, пункт назначения **Мой Mac**, затем скомпилируйте и запустите с помощью Xcode.
4. Активируйте расширение в **Safari → Настройки → Расширения**, затем авторизуйте нужные сайты.
5. Откройте настройки расширения и настройте свой NAS, как описано ниже.

Примеры идентификаторов пакетов: `com.example.UGREENNASDownload` и `com.example.UGREENNASDownload.Extension`. Если вам нужно настроить их для своей подписи, измените идентификаторы проекта Xcode **и** соответствующие константы в `Extension/background.js` и `ViewController.swift`: значения должны оставаться согласованными.

В этой общедоступной версии используются идентификаторы и пространство «Связка ключей» отдельно от приложения для персональной разработки. Для этого требуется собственная конфигурация NAS. Подпись разработки не является нотариально заверенным распространением, и для активации могут потребоваться настройки разработки Safari, соответствующие вашей подписи.

Чтобы проверить компиляцию без подписи, из корня репозитория:

```sh
xcodebuild \
  -project "Xcode/UGREEN NAS Download/UGREEN NAS Download.xcodeproj" \
  -scheme "UGREEN NAS Download" \
  -configuration Release -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath ./build CODE_SIGNING_ALLOWED=NO build
```

Эта проверка создает неподписанное приложение; используйте команду Apple для разработки установки, которую можно будет использовать в Safari. Сохраните дерево репозитория: ссылки от Xcode до `Extension` и `Design` являются относительными.

## Настроить NAS

1. Введите адрес HTTPS из NAS с его портом, вашим идентификатором и абсолютным путем назначения на NAS. Личные поля по умолчанию пусты.
2. Нажмите **Проверить сертификат NAS**. Сравните отпечаток SHA-256 с доверенным источником, прежде чем подтверждать сертификат.
3. Введите пароль и, при необходимости, код двойной аутентификации. Доверять устройству необязательно; без него может потребоваться новый код по истечении сеанса.
4. Нажмите **Сохранить и проверить соединение**. Разрешить доступ к локальной сети, когда macOS запросит его.
5. При желании включите автоматический перехват торрентов и магнитов. Щелчок правой кнопкой мыши и отправка вручную остаются независимыми от этого переключателя.

Адрес, учетную запись и папку по-прежнему можно изменить в настройках. **Если вы забудете эту учетную запись**, учетная запись и ее сеанс связки ключей будут удалены для текущего профиля Safari.

## Безопасность и эксплуатация

Веб-страницы не могут настроить учетную запись или доверять сертификату. Расширение взаимодействует со своим модулем Swift через собственный обмен сообщениями. NAS запросы проходят через изолированный механизм WebKit с отключенным эфемерным хранилищем и страничными сценариями; сертификат должен совпадать с утвержденным отпечатком пальца. NAS редиректы запрещены. Пароль зашифрован ключом RSA, предоставленным NAS, на HTTPS.

Пароль, токен и информация для входа хранятся в Keychain, а не в веб-хранилище или этом репозитории. Временный код стирается после использования. Файлы cookie и идентификаторы сайтов Safari никогда не передаются на NAS. Для некоторых торрентов с одного и того же сайта небольшой файл извлекается в память с помощью сеанса Safari, затем передается на NAS без локального сохранения или SMB; его размер ограничен 512 КиБ.

Автоматический поиск добровольно запрашивает `api.ugnas.com`: этот сервис видит публичный IP-адрес соединения, но не получает пароль или токен NAS. Ручной ввод не зависит от данной услуги.

Никаких новых дополнений не предпринимается после двусмысленного ответа или истечения крайнего срока. Повторное подключение и новая попытка разрешены только после явного отказа в аутентификации. **Задача, принятая NAS, не является доказательством завершения загрузки.**

## Пределы

- Safari не заменяет все загрузки. Автоматический перехват охватывает распознанные торрент-ссылки и механизмы; щелчок правой кнопкой мыши и ввод вручную завершают эту операцию.
- Ссылка HTTP должна быть доступна напрямую пользователю NAS. Защищенное содержимое сеанса сайта, срок действия которого истек URL, защищенные видео и обычные файлы, созданные в `blob:` или `data:`, не преобразуются в общедоступные ссылки.
- Отслеживание меню ожидает примерно 3,5 секунды после каждого ответа; уведомления и исправления имен проверяются примерно каждые 30 секунд. Safari закрыт, приостановлен или спящий Mac может задержать эти операции.
- Неизвестные форматы не получают придуманного расширения. Переименование происходит после завершения загрузки; фактический файл фиксируется, а история загрузок может сохранить свое исходное имя.
- Исправления по-прежнему ограничиваются новыми задачами HTTP, однозначно определенными, без принудительной замены, с максимум 100 ожидающими операциями и сроком хранения семь дней. Списки ограничены 10 000 задачами в каждой категории.
- Глобальная настройка macOS значков остается приоритетной: **Темный → Автоматически** позволяет вам следовать теме. Значок статического списка расширений Safari сохраняет свою чистую версию; логотипы меню и опций соответствуют теме.

## Разработка и тестирование

```sh
node --test Tests/autonomous.test.cjs
bash Tests/run-native-tests.sh
```

Для тестирования JavaScript требуется Node.js; Для собственного тестирования требуются инструменты macOS, Xcode, Python 3 и OpenSSL. Они запускают временный локальный сервер HTTPS на порту 18443 и не используют настоящую учетную запись NAS. Аудит версии 0.5.1 включал 45 тестов JavaScript и 121 встроенный элемент управления. См. [отчет](../AUDIT-0.5.1.md).

- `Extension/`: меню, настройки, скрипты Safari и иконки.
- `Xcode/`: приложение AppKit, модуль Swift, аутентификация и транспорт NAS.
- `Design/Adaptive/UGREENIcon.icon/`: Собственный значок со светлым и темным внешним видом.
- `Design/generate-icons.swift`: генерация PNG и адаптивный логотип окна.
- `Tests/`: тесты безопасности, проверка данных и поведение.
