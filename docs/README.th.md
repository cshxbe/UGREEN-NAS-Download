## คุณสมบัติ

- การสกัดกั้นลิงก์ `.torrent` และ `magnet:` บนไซต์ที่ได้รับอนุญาตใน Safari
- การดำเนินการ **ดาวน์โหลดไปที่ NAS** โดยการคลิกขวาที่องค์ประกอบลิงก์ รูปภาพ วิดีโอ หรือเสียงที่เข้าถึงได้โดยตรง
- การส่ง URL ด้วยตนเองจากเมนูส่วนขยาย
- บัญชีและเซสชันในพวงกุญแจ macOS; รองรับการรับรองความถูกต้องด้วยสองปัจจัยและความน่าเชื่อถือของอุปกรณ์
- ค้นหาเพิ่มเติมสำหรับ NAS โดยใช้บริการออนไลน์ UGREEN หรือที่อยู่ HTTPS ด้วยตนเอง
- รายการดาวน์โหลด ความคืบหน้าและความเร็ว การปิดระบบ และการแจ้งเตือนข้อผิดพลาดที่เป็นทางเลือก
- การระบุชื่อไฟล์และประเภท HTTP พร้อมการแก้ไขชื่อหลังจากดาวน์โหลด เมื่อมีการระบุไฟล์อย่างไม่คลุมเครือ
- ไอคอนแสงและความมืดดั้งเดิม และโลโก้ Safari ปรับให้เข้ากับธีมของระบบ

## ความเข้ากันได้

โปรเจ็กต์ได้รับการกำหนดค่าสำหรับ **macOS 27 หรือใหม่กว่า** และคอมไพล์ด้วย **Xcode 27.1** สำหรับ Apple Silicon การทดสอบ NAS ดำเนินการด้วย **DXP2800**, **UGOS Pro 1.20.0.0142** และ **ดาวน์โหลด 1.19.1.0004** ไม่รับประกันเวอร์ชันอื่นๆ: การบูรณาการจะขึ้นอยู่กับ API ที่สังเกตได้ โดยไม่มีสัญญาสาธารณะ UGREEN ที่มีเสถียรภาพ

[ดาวน์โหลด UGREEN NAS Download 0.6.0 สำหรับ Mac Apple Silicon](https://github.com/cshxbe/UGREEN-NAS-Download/releases/tag/v0.6.0)

2. ใน **Safari → การตั้งค่า → ขั้นสูง** เปิดใช้งานคุณสมบัติสำหรับนักพัฒนาเว็บ ใน **นักพัฒนา** ให้เปิดใช้งาน **อนุญาตส่วนขยายที่ไม่ได้ลงนาม** จากนั้นเปิดใช้งาน **UGREEN NAS Download** ใน **ส่วนขยาย**
3. กำหนดค่า NAS ในการตั้งค่าส่วนขยาย

แพ็คเกจสาธารณะนี้มีการลงนามในเครื่อง (เฉพาะกิจ) และไม่มีการรับรอง macOS อาจปิดกั้นการเปิดครั้งแรก Safari อาจขอให้เปิดใช้งานการอนุญาตอีกครั้งสำหรับส่วนขยายที่ไม่ได้ลงนามหลังจากออกจากเบราว์เซอร์

## เรียบเรียงจากแหล่งที่มา

1. โคลนที่เก็บนี้และเปิด `Xcode/UGREEN NAS Download/UGREEN NAS Download.xcodeproj`
2. ใน **การลงนามและความสามารถ** ให้เลือกทีม Apple ของคุณเองสำหรับสองเป้าหมาย: แอปพลิเคชันและส่วนขยาย ไม่มีการป้อนทีมส่วนบุคคลลงในที่เก็บ
3. เลือกรูปแบบ **UGREEN NAS Download** ปลายทาง **My Mac** จากนั้นคอมไพล์และเปิดใช้งานด้วย Xcode
4. เปิดใช้งานส่วนขยายใน **Safari → การตั้งค่า → ส่วนขยาย** จากนั้นให้อนุญาตไซต์ที่ต้องการ
5. เปิดการตั้งค่าส่วนขยายและกำหนดค่า NAS ของคุณตามที่อธิบายไว้ด้านล่าง

รหัสชุดตัวอย่างคือ `com.example.UGREENNASDownload` และ `com.example.UGREENNASDownload.Extension` หากคุณต้องการปรับแต่งสำหรับลายเซ็นของคุณ ให้แก้ไขตัวระบุโปรเจ็กต์ Xcode **และ** ค่าคงที่ที่สอดคล้องกันใน `Extension/background.js` และ `ViewController.swift`: ค่าจะต้องสอดคล้องกัน

ฉบับสาธารณะนี้ใช้ตัวระบุและพื้นที่พวงกุญแจแยกจากแอปพลิเคชันการพัฒนาส่วนบุคคล ต้องมีการกำหนดค่าของตัวเองเป็น NAS ลายเซ็นการพัฒนาไม่ถือเป็นการแจกจ่ายและการเปิดใช้งานที่ได้รับการรับรองอาจต้องมีการตั้งค่าการพัฒนา Safari ที่เหมาะสมสำหรับลายเซ็นของคุณ

หากต้องการตรวจสอบการคอมไพล์โดยไม่มีลายเซ็น จากรูทของที่เก็บ:

```sh
xcodebuild \
  -project "Xcode/UGREEN NAS Download/UGREEN NAS Download.xcodeproj" \
  -scheme "UGREEN NAS Download" \
  -configuration Release -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath ./build CODE_SIGNING_ALLOWED=NO build
```

การตรวจสอบนี้จะสร้างแอปพลิเคชันที่ไม่ได้ลงนาม ใช้ทีม Apple ของคุณสำหรับการติดตั้งการพัฒนาที่ใช้งานได้ใน Safari เก็บแผนผังที่เก็บ: การอ้างอิง Xcode ถึง `Extension` และ `Design` มีความสัมพันธ์กัน

## กำหนดค่า NAS

1. ป้อนที่อยู่ HTTPS ของ NAS พร้อมด้วยพอร์ต ตัวระบุของคุณ และเส้นทางปลายทางที่แน่นอนบน NAS ช่องส่วนบุคคลจะว่างเปล่าตามค่าเริ่มต้น
2. คลิก **ตรวจสอบใบรับรองของ NAS** เปรียบเทียบลายนิ้วมือ SHA-256 กับแหล่งที่เชื่อถือได้ก่อนที่จะยืนยันใบรับรอง
3. ป้อนรหัสผ่านและรหัสยืนยันตัวตนซ้ำหากจำเป็น การเชื่อถืออุปกรณ์นั้นเป็นทางเลือก หากไม่มีอาจต้องใช้รหัสใหม่เมื่อเซสชันหมดอายุ
4. คลิก **บันทึกและทดสอบการเชื่อมต่อ** อนุญาตการเข้าถึงเครือข่ายท้องถิ่นเมื่อ macOS ร้องขอ
5. เปิดใช้งานการสกัดกั้นกระแสน้ำและแม่เหล็กอัตโนมัติหากต้องการ การคลิกขวาและการส่งด้วยตนเองยังคงไม่ขึ้นอยู่กับสวิตช์นี้

ที่อยู่ บัญชี และโฟลเดอร์ยังคงสามารถแก้ไขได้ในการตั้งค่า **การลืมบัญชีนี้** จะลบบัญชีและเซสชันพวงกุญแจของโปรไฟล์ปัจจุบัน Safari

## ความปลอดภัยและการดำเนินงาน

เว็บเพจไม่สามารถกำหนดค่าบัญชีหรือเชื่อถือใบรับรองได้ ส่วนขยายสื่อสารกับโมดูล Swift ผ่านการส่งข้อความแบบเนทีฟ คำขอ NAS ดำเนินการผ่านกลไก WebKit ที่แยกออกมา โดยที่พื้นที่เก็บข้อมูลชั่วคราวและสคริปต์เพจถูกปิดใช้งาน ใบรับรองจะต้องตรงกับลายนิ้วมือที่ได้รับอนุมัติ NAS การเปลี่ยนเส้นทางถูกปฏิเสธ รหัสผ่านถูกเข้ารหัสด้วยคีย์ RSA ที่ได้รับจาก NAS บน HTTPS

รหัสผ่าน โทเค็น และข้อมูลการเข้าสู่ระบบจะถูกจัดเก็บไว้ในพวงกุญแจ ไม่ใช่ในพื้นที่จัดเก็บข้อมูลบนเว็บหรือพื้นที่เก็บข้อมูลนี้ รหัสชั่วคราวจะถูกลบหลังการใช้งาน คุกกี้และตัวระบุไซต์ Safari จะไม่ถูกส่งไปยัง NAS สำหรับทอร์เรนต์บางรายการจากไซต์เดียวกัน ไฟล์ขนาดเล็กจะถูกดึงข้อมูลในหน่วยความจำด้วยเซสชัน Safari จากนั้นส่งไปที่ NAS โดยไม่ต้องบันทึกในเครื่องหรือ SMB; ขนาดของมันจำกัดอยู่ที่ 512 KiB

การค้นหาอัตโนมัติสอบถาม `api.ugnas.com` โดยสมัครใจ: บริการนี้เห็นที่อยู่ IP สาธารณะของการเชื่อมต่อ แต่ไม่ได้รับรหัสผ่านหรือโทเค็น NAS การป้อนข้อมูลด้วยตนเองไม่ได้ขึ้นอยู่กับบริการนี้

ไม่มีการพยายามเพิ่มเติมใหม่หลังจากการตอบกลับที่ไม่ชัดเจนหรือเลยกำหนดเวลาไปแล้ว การเชื่อมต่อใหม่และความพยายามใหม่จะได้รับอนุญาตหลังจากการปฏิเสธการรับรองความถูกต้องอย่างชัดเจนเท่านั้น **งานที่ยอมรับโดย NAS ไม่ใช่ข้อพิสูจน์ว่าการดาวน์โหลดเสร็จสมบูรณ์**

## ขีดจำกัด

- Safari ไม่ได้แทนที่การดาวน์โหลดทั้งหมดแบบสากล การสกัดกั้นอัตโนมัติครอบคลุมลิงก์และกลไกทอร์เรนต์ที่ได้รับการยอมรับ การคลิกขวาและป้อนข้อมูลด้วยตนเองทำให้การดำเนินการนี้เสร็จสมบูรณ์
- ลิงก์ HTTP ต้องเข้าถึงได้โดยตรงโดย NAS เนื้อหาที่ได้รับการป้องกันเซสชันของไซต์ หมดอายุ URL วิดีโอที่ได้รับการป้องกันและไฟล์ธรรมดาที่สร้างใน `blob:` หรือ `data:` จะไม่ถูกแปลงเป็นลิงก์สาธารณะ
- การติดตามเมนูจะรอประมาณ 3.5 วินาทีหลังจากการตอบกลับแต่ละครั้ง การแจ้งเตือนและการแก้ไขชื่อจะถูกตรวจสอบทุกๆ 30 วินาทีโดยประมาณ Safari ปิด ถูกระงับ หรือ Mac ที่กำลังหลับอาจทำให้การทำงานเหล่านี้ล่าช้า
- รูปแบบที่ไม่รู้จักไม่ได้รับส่วนขยายที่ประดิษฐ์ขึ้น การเปลี่ยนชื่อเกิดขึ้นหลังจากการดาวน์โหลดเสร็จสิ้น ไฟล์จริงได้รับการแก้ไขแล้ว ในขณะที่ประวัติการดาวน์โหลดสามารถคงชื่อเดิมไว้ได้
- การแก้ไขยังคงจำกัดอยู่ที่งานใหม่ HTTP ที่ระบุอย่างชัดเจน โดยไม่ต้องบังคับเปลี่ยน โดยมีการดำเนินการที่รอดำเนินการสูงสุด 100 รายการและการเก็บรักษาไว้เจ็ดวัน รายการจำกัดไว้ที่ 10,000 งานต่อหมวดหมู่
- การตั้งค่าส่วนกลาง macOS ของไอคอนยังคงมีความสำคัญ: **มืด → อัตโนมัติ** ช่วยให้คุณสามารถติดตามธีมได้ ไอคอนรายการส่วนขยายแบบคงที่ Safari ยังคงรักษาเวอร์ชันที่ชัดเจนไว้ โลโก้เมนูและตัวเลือกเป็นไปตามธีม

## การพัฒนาและการทดสอบ

```sh
node --test Tests/autonomous.test.cjs
bash Tests/run-native-tests.sh
```

การทดสอบ JavaScript ต้องใช้ Node.js; การทดสอบแบบเนทีฟต้องใช้เครื่องมือ macOS, Xcode, Python 3 และ OpenSSL พวกเขาเริ่มต้นเซิร์ฟเวอร์ HTTPS ภายในชั่วคราวบนพอร์ต 18443 และไม่ใช้บัญชี NAS จริงใดๆ การตรวจสอบ 0.5.1 ประกอบด้วยการทดสอบ JavaScript 45 รายการ และการควบคุมแบบเนทิฟ 121 รายการ ดู [รายงาน](../AUDIT-0.5.1.md)

- `Extension/`: เมนู การตั้งค่า สคริปต์ Safari และไอคอน
- `Xcode/`: แอปพลิเคชัน AppKit, โมดูล Swift, การตรวจสอบสิทธิ์และการขนส่ง NAS
- `Design/Adaptive/UGREENIcon.icon/`: ไอคอนดั้งเดิมที่มีรูปลักษณ์สว่างและมืด
- `Design/generate-icons.swift`: การสร้าง PNG และโลโก้ที่ปรับเปลี่ยนได้ของหน้าต่าง
- `Tests/`: การทดสอบความปลอดภัย การตรวจสอบข้อมูล และพฤติกรรม
