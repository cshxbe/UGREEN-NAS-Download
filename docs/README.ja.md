# UGREEN NAS Download

[English](../README.md) · [Français](README.fr.md) · [🌐 34](LANGUAGES.md)

macOS アプリと Safari 拡張機能。NAS ページを開いたままにせず、UGOS Pro にあるNAS UGREEN の **ダウンロード** アプリにダウンロードを送信します。

ソースと DMG バージョン: **0.6.1**。 UGREEN や Apple とは関係のない、独立したコミュニティ プロジェクトです。

## 特長

- Safari で認可されたサイト上のリンク `.torrent` および `magnet:` の傍受。
- アクション **直接アクセス可能なリンク、画像、ビデオ、またはオーディオ要素を右クリックして、NAS** にダウンロードします。
- 拡張機能メニューからURL を手動で送信します。
- キーチェーンのアカウントとセッション macOS; 2 要素認証とデバイスの信頼のサポート。
- オプションで、UGREEN オンライン サービスを使用して NAS を検索するか、手動でアドレス HTTPS を検索します。
- ダウンロード、進行状況、速度のリスト。オプションの完了、シャットダウン、エラー通知。
- ファイル名とタイプの識別 HTTP。ファイルが明確に識別された場合は、ダウンロード後に名前が修正されます。
- ネイティブの明るいアイコンと暗いアイコン、およびシステムテーマに合わせたSafari ロゴ。

## 互換性

プロジェクトは **macOS 27 以降** 向けに構成されており、Apple Silicon 用に **Xcode 27.1** でコンパイルされました。 NAS テストは、**DXP2800**、**UGOS Pro 1.20.0.0142**、**ダウンロード 1.19.1.0004** を使用して実行されました。他のバージョンは保証されていません。統合は、安定した UGREEN 公的契約なしで、監視されている API に基づいています。

## DMGからインストール

[Mac Apple Silicon](https://github.com/cshxbe/UGREEN-NAS-Download/releases/tag/v0.6.1) 用 UGREEN NAS Download 0.6.1 をダウンロードします。

1. DMG を開き、**UGREEN NAS Download** を **アプリケーション** にドラッグして、アプリを開きます。
2. **Safari → 設定 → 詳細** で、Web 開発者向けの機能を有効にします。 **開発者**で**署名されていない拡張機能を許可**を有効にし、**拡張機能**で**UGREEN NAS Download**を有効にします。
3. 拡張機能の設定で NAS を設定します。

このパブリック パッケージはローカルで (アドホックに) 署名されており、公証されていません。 macOS が最初の開口部をブロックする可能性があります。 Safari は、ブラウザを終了した後、未署名の拡張機能の許可を再度有効にするよう要求する場合があります。

## ソースからコンパイルする

1. このリポジトリのクローンを作成し、`Xcode/UGREEN NAS Download/UGREEN NAS Download.xcodeproj` を開きます。
2. **署名と機能** で、アプリケーションとその拡張機能の 2 つのターゲットに対して独自の Apple チームを選択します。個人チームはリポジトリに入力されません。
3. スキーム **UGREEN NAS Download**、宛先 **My Mac** を選択し、Xcode でコンパイルして起動します。
4. **Safari → 設定 → 拡張機能** で拡張機能を有効にして、目的のサイトを認証します。
5. 拡張機能の設定を開き、以下の説明に従って NAS を設定します。

バンドル ID の例は、`com.example.UGREENNASDownload` と `com.example.UGREENNASDownload.Extension` です。署名用にカスタマイズする必要がある場合は、プロジェクト識別子 Xcode ** および ** `Extension/background.js` と `ViewController.swift` の対応する定数を変更します。値は一貫性を保つ必要があります。

このパブリック エディションは、個人開発アプリケーションとは別の識別子とキーチェーン スペースを使用します。独自の構成 NAS が必要です。開発署名は公証された配布を構成するものではなく、アクティベーションには署名に適した開発設定 Safari が必要な場合があります。

署名のないコンパイルをチェックするには、リポジトリのルートから次のようにします。

```sh
xcodebuild \
  -project "Xcode/UGREEN NAS Download/UGREEN NAS Download.xcodeproj" \
  -scheme "UGREEN NAS Download" \
  -configuration Release -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath ./build CODE_SIGNING_ALLOWED=NO build
```

このチェックにより、署名されていないアプリケーションが生成されます。 Safari で使用可能な開発インストールには Apple チームを使用してください。リポジトリ ツリーを保持します。参照 Xcode から `Extension` および `Design` は相対的です。

## NASを設定します

1. NAS のアドレス HTTPS とそのポート、識別子、および NAS の絶対宛先パスを入力します。個人フィールドはデフォルトでは空です。
2. **NAS** の証明書を確認するをクリックします。証明書を確認する前に、フィンガープリント SHA-256 を信頼できるソースと比較してください。
3. パスワードを入力し、必要に応じて二重認証コードを入力します。デバイスを信頼するかどうかはオプションです。これがないと、セッションの有効期限が切れたときに新しいコードが必要になる場合があります。
4. **保存して接続をテスト** をクリックします。 macOS が要求した場合、ローカル ネットワークへのアクセスを許可します。
5. 必要に応じて、トレントとマグネットの自動傍受を有効にします。右クリックと手動送信は、このスイッチとは独立したままになります。

アドレス、アカウント、フォルダーは設定で変更できます。 **このアカウントを忘れると**、現在のプロファイル Safari のアカウントとそのキーチェーン セッションが削除されます。

## 安全性と操作性

Web ページではアカウントを構成したり、証明書を信頼したりすることはできません。拡張機能は、ネイティブ メッセージングを介して Swift モジュールと通信します。 NAS リクエストは、一時ストレージとページ スクリプトが無効になった分離された WebKit エンジンを通過します。証明書は承認された指紋と一致する必要があります。 NAS リダイレクトは拒否されます。パスワードは、HTTPS の NAS によって提供されたキー RSA を使用して暗号化されます。

パスワード、トークン、ログイン情報は、Web ストレージやこのリポジトリではなく、キーチェーンに保存されます。一時コードは使用後消去されます。 Cookie とサイト識別子 Safari が NAS に送信されることはありません。同じサイトの一部の torrent では、小さなファイルがセッション Safari でメモリ内に取得され、ローカルに保存されずに NAS に送信されるか、SMB に送信されます。サイズは 512 KiB に制限されています。

自動検索は自発的に `api.ugnas.com` をクエリします。このサービスは接続のパブリック IP アドレスを確認しますが、パスワードやトークン NAS は受け取りません。手入力は本サービスに依存しません。

曖昧な応答または期限が経過した後は、新たな追加は試行されません。再接続と新たな試行は、認証を明示的に拒否した場合にのみ許可されます。 **NAS によって受け入れられたタスクは、ダウンロードが完了したことを証明するものではありません。**

## 限界

- Safari は、すべてのダウンロードを普遍的に置き換えるわけではありません。自動インターセプトは、認識されたトレント リンクとメカニズムをカバーします。右クリックして手動で入力すると、この操作が完了します。
- リンク HTTP は、NAS から直接アクセスできる必要があります。サイト セッションで保護されたコンテンツ、期限切れの URL、保護されたビデオ、および `blob:` または `data:` で生成された通常のファイルは、パブリック リンクに変換されません。
- メニュー追跡は、各応答後に約 3.5 秒待機します。通知と名前の修正は約 30 秒ごとにチェックされます。 Safari が閉じられている、一時停止されている、またはスリープ状態の Mac では、これらの操作が遅れる可能性があります。
- 不明な形式は、作成された拡張子を受け取りません。名前の変更は、ダウンロードの完了後に行われます。実際のファイルは修正されますが、ダウンロード履歴は元の名前を維持できます。
- 修正は、強制的に置き換えることなく、明確に識別された新しいタスク HTTP に限定され、保留中の操作は最大 100 件、保持期間は 7 日間です。リストはカテゴリごとに 10,000 タスクに制限されています。
- アイコンのグローバル設定 macOS の優先順位は維持されます: **Dark → Automatic** により、テーマに従うことができます。静的拡張子リスト アイコン Safari はクリア バージョンのままです。メニューとオプションのロゴはテーマに従っています。

## 開発とテスト

```sh
node --test Tests/autonomous.test.cjs
bash Tests/run-native-tests.sh
```

JavaScript のテストには Node.js が必要です。ネイティブ テストには、macOS、Xcode ツール、Python 3、および OpenSSL が必要です。彼らは一時的なローカル HTTPS サーバーをポート 18443 で起動し、実際の NAS アカウントは使用しません。 0.5.1 の監査には、45 の JavaScript テストと 121 のネイティブ コントロールが含まれていました。 [レポート](../AUDIT-0.5.1.md)]を参照してください。

- `Extension/`: メニュー、設定、スクリプト Safari およびアイコン。
- `Xcode/`: AppKit アプリケーション、Swift モジュール、認証およびトランスポート NAS。
- `Design/Adaptive/UGREENIcon.icon/`: 明るい外観と暗い外観を持つネイティブアイコン。
- `Design/generate-icons.swift`: PNG とウィンドウのアダプティブ ロゴの生成。
- `Tests/`: セキュリティテスト、データ検証および動作。
